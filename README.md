# VibeCoding Chat

## Description

A real-time web chat application.

## Features

*   User authentication (login and registration)
*   Real-time messaging
*   User list display
*   Groups
*   Dark/Light theme
*   Edit and delete messages
*   User avatars

## Tech Stack

**Frontend:**
*   React
*   TypeScript
*   Vite
*   Tailwind CSS

**Backend:**
*   Python
*   FastAPI
*   Firebase

## How to run locally

### Backend

1.  Navigate to the `VibeCodingChat/backend` directory:
    ```bash
    cd VibeCodingChat/backend
    ```
2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3.  Run the server:
    ```bash
    python -m uvicorn main:app --reload
    ```

### Frontend

1.  Navigate to the `VibeCodingChat/frontend` directory:
    ```bash
    cd VibeCodingChat/frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the application:
    ```bash
    npm run dev
    ```
